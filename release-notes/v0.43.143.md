## 更新内容

- 改进：个人词典按读音找词：名字被识别成发音相同或相近的别的字（比如「唐豆」「优米路」「リスム」），也会改回词典里的写法，不用每种错法都添加一遍。
- 改进：用另一台设备的 Qwen3-ASR 识别时，也会告诉它个人词典里的词，名字更容易一次听对。
- 修复：用另一台设备识别时，开始再停止会话后，「模型」就不能选了。

## What's new

- Improved: the personal dictionary finds a word by how it sounds: a name recognized as other characters that sound the same or close (such as 唐豆, 优米路 or リスム) is put back as the dictionary writes it, so each wrong spelling no longer has to be added.
- Improved: Qwen3-ASR on another device is told the personal dictionary's words too, so names come out right more often.
- Fixed: with another device listening, the Model menu could no longer be changed after a session was started and stopped.
