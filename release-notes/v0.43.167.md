## 更新内容

**识别**
- 「API」里可以选 DeepSeek 的语音识别：填 key 就能用，不用选模型。它不能指定语言，日语短句偶尔会被写成中文；电脑带得动时，本机模型更准，出字也更快。
- 识别 API 繁忙时会自动再试一次，不再直接丢掉这一句。
- 在「我也会说」里选了英语、法语这类用拉丁字母的语言时，句子里夹着几个汉字不会再被整句丢掉。

## What's new

**Recognition**
- DeepSeek's speech recognition can be chosen under "API": enter a key, there is no model to pick. It cannot be told a language, and a short Japanese reply now and then comes back in Chinese; where the computer can run one, an on-device model is more accurate and writes sooner.
- A recognition API that is busy is asked once more, instead of the sentence being dropped.
- With a language written in Latin letters (English, French) chosen under "I also speak", a sentence that has a few Han characters in it is no longer dropped.
