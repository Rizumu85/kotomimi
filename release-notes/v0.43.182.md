## 更新内容

**朗读和显存**
- 朗读的加速模式会越用越占显存（最多多约 1.6 GB），现在只在 16 GB 及以上、而且显存够的显卡上自动打开。8 GB、10 GB 的显卡不会再因为它把显存挤满。
- 设置 → 帮助里新增两个实验性选项（NVIDIA 显卡才有）：识别和朗读用哪种引擎（自动 / CUDA / Vulkan），以及朗读加速（显存够时 / 总是 / 不加速）。卡顿时可以切换对比；第一次切换要下载另一种引擎，之后来回切换不用再下载。

**诊断日志**
- 打开诊断日志后，会话中每分钟记录一次识别、朗读、翻译和 VRChat 各占多少显存，显存不够时能直接看出来。
- 日志面板新增「导出」按钮，可以存成文件发给我们。

## What's new

**Reading aloud and video memory**
- The voice's speed mode takes more video memory the longer it runs (up to about 1.6 GB more), so it now turns itself on only on cards of 16 GB or more with room to spare. 8 GB and 10 GB cards are no longer filled by it.
- Two experimental choices in Settings → Help (NVIDIA cards only): which engine runs recognition and the voice (automatic, CUDA or Vulkan), and the voice speed-up (when there is room, always, never). Switch between them to compare when something stutters; the first switch downloads the other engine, later switches download nothing.

**Diagnostic logs**
- With diagnostic logs on, a session records every minute how much video memory recognition, the voice, translation and VRChat each take, so a full card shows at once.
- The logs panel has an Export button that saves the logs as a file to send us.
