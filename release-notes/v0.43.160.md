## 更新内容

**模型怎么搭，帮你配好**
- 设置 → 提供商最上面新增「方案」：「轻量 / 均衡 / 精准」三档，写着大约占多少显存、还要下载多少，适合这台电脑的带星。点「用这个方案」才下载，下载完自动切换。平时收成一行，不打扰。第一次设置向导的最后一步也能选。
- 模型库里每个模型标着「可流畅运行 / 可能卡顿 / 无法运行」，鼠标停上去看具体占多少显存。
- 新增 X-ASR 中英识别模型：只用 CPU，不占显卡，边说边出字。自己说中文或英文时，「我说」可以用它，显卡留给游戏和对方那边的识别。
- 两边用同一个模型时只显示一行；跑不了的搭配不再能选上，会变灰并写明原因，以前存下的冲突可以一键统一。
- 「我说」用的模型听不了你点亮的某种语言时，会标出来，并给一个一键换模型的按钮。
- 使用中某个环节一直跟不上时，底部提醒一次，可以直接去看方案。测试速度挪到方案卡片里，测过才显示结果。

**VRChat**
- 你说话时头顶会显示 VRChat 自带的「正在输入」气泡，翻译发出去时消失。
- 长翻译切成几页发到聊天框时，每页停留的时间按字数算，不会还没看完就被下一页盖掉。
- 人多吵杂时，不再把个性化词典里的词凭空加进句子。

**其他**
- 修正了几种语言组合下的识别和翻译问题，例如也会说的另一种语言没有翻回母语、简体转繁体被跳过；局域网字幕页按每句的语言显示译文。
- 字幕设置最下面新增「保存刚才的字幕」：排版出问题时，把最近一分钟的字幕存成文件发给开发者，就能原样重现。
- 引导新增语言、个性化词典、VRChat 三步；「我说」里只有母语时显示「+ 我也会说」；回声消除两个选项的说明写得更清楚。
- 新的安装动画；安装完成后动画会及时关闭。

## What's new

**Models paired for you**
- Plans at the top of Settings → Provider: Light / Balanced / Accurate, each with its video memory and what is left to download, the one for this computer starred. "Use this plan" downloads and switches when ready. Folded to one line once set up, and on the setup's last step.
- Each model in the library says whether it runs smoothly, may lag or cannot run on this computer, with the numbers on hover.
- New: X-ASR, Chinese and English recognition on the CPU alone, writing as you speak. Your side can use it while the graphics card serves the game and the other side.
- Rows on one model are one row; combinations that cannot run are greyed with the reason, and an old clash is fixed with one press.
- A language your side's model cannot hear is marked, with a one-press switch.
- When a stage keeps falling behind, one notice offers the plans. The speed test moved onto the plan card, its results shown once run.

**VRChat**
- VRChat's typing bubble shows while you speak, until the translation goes up.
- Each page of a long translation in the chatbox stays up long enough to read.
- In a noisy, crowded room, glossary words are no longer slipped into sentences.

**Also**
- Several language combinations heard, tagged or translated wrongly are fixed; the LAN caption page picks each line by its language.
- "Save what the subtitle just showed", at the foot of the subtitle settings: a file the developer can replay exactly.
- The tour shows the languages, the glossary and VRChat; "I speak" with only your own language shows "+ I also speak"; the echo cancellation choices say plainly when each fits.
- A new install animation, which closes with the install.
