## 更新内容

- 修复：更新到新版后，已经下载的模型会显示成"没有下载"，开始时也提示要先下载模型，像是模型丢了。其实只是引擎换了新版本。现在 Kotomimi 启动后会自己在后台更新引擎，模型卡片上写着"正在更新引擎"，开始时会说"正在更新引擎，完成后就能开始"；没联网时卡片上有"更新"按钮。旧版引擎会自动删掉，不再占用硬盘。

## What's new

- Fixed: after an update, models already downloaded were shown as not downloaded, and a start asked for a model to be downloaded first, as though the models were lost. Only the engine had a new version. Kotomimi now updates the engine by itself in the background after starting; the model's card says "Updating the engine", and a start says the engine is being updated and you can start once it is done. Offline, the card has an Update button. The earlier engine is removed, and takes no more room on the drive.
