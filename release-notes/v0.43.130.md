## 更新内容

- 在其他设备上选了 Mac 的 Apple Speech 时，现在会真的用 Apple Speech 识别，不会再被 Mac 上正在运行的 Qwen3-ASR 顶替。
- 语音识别选模型时，能看到所有已下载的原生模型，不再因为开着"自动检测"就只剩 Qwen3-ASR 1.7B。选了不能识别语言的模型时，"自动检测"会自动关掉，不会再被悄悄换回 Qwen3。
- 语言设置里的"自动检测"和"我也说××语"按实际情况显示：当前的语音识别做不到时，显示实际的语言，选项变灰并说明原因；用这台电脑的模型时选"自动检测"，会自动换成能识别语言的模型。

## What's new

- When another device chooses the Mac's Apple Speech, Apple Speech is now what recognizes, instead of the Qwen3-ASR the Mac happens to be running.
- Choosing a speech recognition model now lists every native model downloaded, not only Qwen3-ASR 1.7B while "Auto-detect" is on. Choosing one that cannot detect languages turns "Auto-detect" off, instead of being silently replaced by Qwen3.
- "Auto-detect" and "I speak X too" in the languages now show what a run actually does: where the speech recognition in use cannot detect, the actual language is shown and the choice is greyed with the reason; choosing "Auto-detect" while this computer's own models hear switches to a model that can.
