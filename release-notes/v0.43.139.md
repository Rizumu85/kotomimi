## 更新内容

- 改进：发到 VRChat 聊天框的句子太长时，会分成几条依次发出去，不再被截断。尽量在句子结尾处分开，断在句子中间的那一条末尾带“…”。
- 改进：模型还没下载时，提示会说是哪一类模型没下载，旁边有“下载”按钮，点了直接打开下载的地方。
- 改进：第一次下载模型时，运行引擎和模型合成一条进度条，不会走到一半又从头开始。
- 改进：引导页的语言页上方用几种语言写着“语言”，打开时不管是什么语言，都能认出这是切换语言的页面。
- 修复：系统是繁体中文时，界面默认显示成了简体中文；系统是葡萄牙的葡萄牙语时，默认显示成了巴西葡萄牙语。

## What's new

- Improved: a sentence too long for the VRChat chatbox goes up as several messages, one after another, instead of being cut short. They are split at the end of a sentence where possible; a message split mid-sentence ends with "…".
- Improved: when a model is not downloaded yet, the notice says which kind of model it is, with a Download button that opens where to download it.
- Improved: the first model download shows the runtime and the model on one progress bar, which no longer starts over partway.
- Improved: the language step of the setup guide says "Language" in several languages, so it can be recognized whatever language it opens in.
- Fixed: a Traditional Chinese system was shown the interface in Simplified Chinese, and Portuguese from Portugal was shown Brazilian Portuguese.
