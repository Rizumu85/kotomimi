## 更新内容

- 改进：用 iPad 做另一台设备识别时，可以直接在电脑「语音识别」卡片的「模型」里选 iPad 上的哪个识别模型，不用再到 iPad 上去切换。

## What's new

- Improved: with an iPad listening as another device, the Model menu of the Speech recognition card now chooses which of the iPad's recognition models is used, so it no longer has to be changed on the iPad.
