## 更新内容

- 「另一台设备」列表更清楚了：每台设备写明是电脑、平板还是手机，以及它的地址和有几个模型；正在用的设备会显示它在做哪些环节（识别、翻译、语法反馈）。
- 「重新搜索」改成卡片标题旁的刷新按钮，侧栏窄时不会再被挤成竖排。
- Mac 的名字不再带 `.local`。
- 显示设置里，罗马音下面那一行语言前面标上了「罗马音」，一眼能看出是在选哪些语言显示罗马音。

## What's new

- The "another device" list is clearer: each device says whether it is a computer, a tablet or a phone, with its address and how many models it has; a device in use shows which stages it runs (recognition, translation, feedback).
- "Search again" is now a refresh button beside the card's title, and no longer squeezed into a column in a narrow sidebar.
- A Mac's name no longer ends in `.local`.
- In the display settings, the row of languages under Romanization is now labelled as its own, so it is clear it picks which languages get romanized.
