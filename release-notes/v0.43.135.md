## 更新内容

- 第一次下载模型时能看到进度了：会先下载运行环境，进度显示在你点的模型上。之前所有模型都停在 0%，看起来像卡住了。
- 运行环境增加了更多下载线路，国内网络更容易下载成功。
- 修复：下载刚开始时点取消，下载其实还在继续。
- 个性化词典更好懂了：只填「词语」就行，名字不用重复写；被听错过的词，再在「听错成」里记下来。
- 在对话里选中听错的词，点旁边的「改词」，就能直接改对并记进词典。原文马上改好，从下一句起翻译也用对的词。
- 字幕窗口第一次打开时不再那么大。窗口变窄时，按钮不会再被切掉：放不下的功能会移到字幕设置里。
- 显示设置里的读音和文字选项，整理成了两组小按钮。
- 按钮的提示换成了应用自己的样式。
- 现在所有界面语言都翻译完整了，不会再混着英文。

## What's new

- A first model download now shows its progress: the runtime comes first, and its progress appears on the model you chose. Before, every model sat at 0% and looked stuck.
- The runtime has more download routes, so it gets through more often on networks in China.
- Fixed: cancelling just as a download began did not stop it.
- The personal glossary is clearer: a word is all you need to fill in, so names need no repeating. If a word was misheard, note how under Misheard as.
- Select a misheard word in the conversation and press Fix word to correct it and save it to the glossary. The original text changes at once, and translations use the right word from the next sentence.
- The subtitle window no longer opens so large. When it gets narrow, its buttons are no longer cut off: what does not fit moves to the subtitle settings.
- The reading and text options in the display settings are now two groups of small buttons.
- Button hints now use the app's own style.
- Every interface language is now fully translated, with no English left mixed in.
