## 更新内容

**朗读**
- 去掉了朗读的加速模式。不加速时朗读已经比说话快好几倍，而加速模式会越用越占显存，和游戏一起用时容易把显存撑满、导致卡顿。
- 设置 → 帮助里只保留「引擎」这一个实验性选项（自动 / CUDA / Vulkan，NVIDIA 显卡才有）。

## What's new

**Reading aloud**
- The voice's speed mode is gone. Without it the voice already speaks several times faster than real time, and the speed mode took more video memory the longer it ran, which could fill the card beside a game and make everything stutter.
- Settings → Help keeps one experimental choice: the engine (automatic, CUDA or Vulkan; NVIDIA cards only).
